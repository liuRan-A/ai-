# 模拟面试 AI 助手 — 需求分析文档

> **产品名**：Mockwise · 全真模拟面试
> **版本**：v1.0 草案
> **面向岗位**：AI 方案架构师（可扩展至通用岗位）
> **平台**：Web（PC 端为基线，移动端同步设计）
> **文档状态**：与现有画布原型 + 数据库 schema 同步；后续按业务反馈迭代

---

## 1. 项目概述

### 1.1 一句话定义
面向求职者的 **AI 一对一 / 一对多 模拟面试工具**，支持结构化面试、无领导小组讨论、半结构化面试三种形式，提供「配置—模拟—评估—回放—改进」的闭环训练体验。

### 1.2 背景与机会
- 真实面试机会稀缺、试错成本高，求职者缺乏可以反复练习的环境
- LLM + 语音转写（ASR）+ TTS 的工程链路已经成熟，可承担「面试官 + 评估官」双重角色
- 现有题库类、测评类产品多为单向出题，缺少「真实群面同台发言」的体验

### 1.3 核心价值
| 价值 | 对应功能 |
| --- | --- |
| 反复可练 | 套题库 + 月度配额 + 连续天数 |
| 真实感 | 群面 6 人同台 / 主持人打断 / 抢麦 |
| 可衡量 | 4-5 维度雷达 / 同岗位百分位 / 较上场对比 |
| 可回放 | 语音 + 转写同步 / 高光标记 / 字幕跳转 |

## 2. 目标用户与场景

### 2.1 用户画像

| 画像 | 占比 | 痛点 | 关键诉求 |
| --- | --- | --- | --- |
| 应届 / 校招候选人 | 45% | 缺乏真实面试环境；面试回忆松散 | 「像真的一样来一场，告诉我哪里不好」 |
| 社招 / 跳槽候选人 | 35% | 大厂群面经验少；岗位匹配度存疑 | 「针对 AI 方案架构师这个岗，给我压一压」 |
| 资深从业者转型 | 15% | 不熟悉新岗位的考核维度 | 「给我一段自我介绍 + 一个情景题的视频复盘」 |
| HR / 培训方 | 5% | 班次化测评难组织 | 待 v2.0 探索，不在本期范围内 |

### 2.2 使用场景
1. **通勤路上**（移动端）：刷 2 道结构化面试题，回看昨日回放，挑一道重练
2. **周末整段**（PC 端）：用 25 分钟走完一次完整模拟，看综合报告，针对薄弱维度加练
3. **群面前突击**（PC 端）：进入无领导小组讨论套题，重复练 3 场，对比发言占比与打断次数

## 3. 功能模块

### 3.1 功能地图

```
模拟面试 AI 助手
├── 1. 工作台（首页）
│   ├── 个人数据（剩余次数 / 连续天数 / 平均分 / 最优题数）
│   ├── 推荐练习（按岗位匹配度排序）
│   └── 趋势速览（近 5 场综合分）
├── 2. 面试配置
│   ├── 选面试形式：结构化 / 无领导小组 / 半结构化
│   ├── 选套题（按行业 + 岗位 + 难度）
│   └── 选交互方式：语音 / 文字 / 混合
├── 3. 全真模拟作答
│   ├── 结构化：单题倒计时 + 实时转写 + AI 追问
│   └── 群面：多阶段（个人陈述 → 自由讨论 → 总结陈词）+ 举手发言 + 抢麦
├── 4. 综合评分报告
│   ├── 总分 + 多维度条形图（专业深度 / 逻辑结构 / 语言表达 / 应急应变 / 岗位匹配）
│   ├── 逐题回顾列表（点入看详情）
│   ├── 高光时刻 + 改进建议 + 推荐加练
│   └── 趋势对比（较上场 / 同岗位百分位）
└── 5. 逐题详情 / 回放（报告下钻子页）
    ├── 视频回放 + 倍速 + 字幕
    ├── 时间轴标记的转写全文
    └── 高光时刻 + 改进建议 + 参考答案
```

### 3.2 模块优先级

| 优先级 | 模块 | 说明 |
| --- | --- | --- |
| P0 | 工作台 / 配置 / 作答 / 报告 | 完整主流程 |
| P1 | 群面 / 逐题回放 | 与 P0 同周期交付，作为差异化卖点 |
| P2 | 简历 & JD 解析 | v1.1 规划 |
| P3 | HR 班次化 / 校招批量 | v2.0 探索 |

## 4. 核心业务流程

### 4.1 主流程（四步）
```
[工作台] ── 点击「开始全真模拟」 ──▶ [选面试形式]
   └─ 右上角「本月剩余 3/3 次」「连续 12 天」
                                        │
                ┌───────────────────────┼───────────────────────┐
                ▼                       ▼                       ▼
          结构化面试              无领导小组讨论             半结构化面试
                │                       │                       │
                └─────── [选套题] ──────┴───────────────────────┘
                                  │
                                  ▼
                         [全真模拟作答]
                          ├── 结构化：单题 60s 思考 + 180s 作答，自动切题
                          └── 群面：3 阶段（1min 陈述 / 15min 自由 / 2min 总结）
                                  │
                                  ▼
                         [综合评分报告]
                          ├── 总分 + 5 维度条
                          ├── 逐题卡片（点击进入详情回放）
                          ├── 高光 / 建议 / 加练 CTA
                          └── 趋势对比卡片
```

### 4.2 群面状态机

| 阶段 | 时长 | 用户权限 | AI 行为 |
| --- | --- | --- | --- |
| 个人陈述 | 60s | 自由语音 | 候选人依次陈述 |
| 自由讨论 | 15min | 需「举手」抢发言权 | 主持人引导、点名沉默者、打断抢话者 |
| 总结陈词 | 120s | 自由陈述 | 推举一位候选人做总结 |

### 4.3 异常路径
- **断网 / 退后台**：作答转写本地暂存 → 重连后补传
- **沉默超时**：连续 90s 沉默 → 弹提示「是否主动结束」
- **面试中退出**：扣 1 次配额；30 天内同套题不能再开新场

## 5. 字段表（与 mock_interview_schema.sql 对应）

> 前端展示需要的字段，已在原型中体现。这里给出「卡片字段 → 数据表字段」的映射，方便联调。

### 5.1 工作台首页

| 卡片字段 | 取数来源（SQL 表 / 视图） | 备注 |
| --- | --- | --- |
| 本月剩余 3/3 次 | `v_user_dashboard.simulated_left / simulated_total` | `user_quotas` 月度配额 |
| 连续练习 12 天 | `v_user_dashboard.streak_days` | `user_streaks.current_days` |
| 综合平均分 74.2 | `v_user_dashboard.avg_score_30d` | `practice_history` 30 天滚动均值 |
| 较上场 +6.8 | `reports.total_score` × 最近两场 | 计算字段 |
| 最优作答题数 86 | `v_user_dashboard.best_score` | 实际上是「最优场次得分」 |
| 推荐练习 92% | `question_sets.match_score` | 按当前 `positions.is_active` 关联计算 |
| 历史得分趋势 | `practice_history` 最近 5 条 | 折线图取数 |

### 5.2 选面试形式

| 卡片字段 | 表 / 字段 |
| --- | --- |
| 形式名（结构化 / 群面 / 半结构化） | 枚举映射 `interview_configs.form_type` |
| 描述、预计用时 | `question_sets.est_minutes` |
| 已练习次数 | `interview_sessions` 按 `user_id + form_type` 计数 |

### 5.3 选套题

| 卡片字段 | 表 / 字段 |
| --- | --- |
| 套题名 / 行业 / 岗位 | `question_sets.name / industry / position_type` |
| 题数 / 预计用时 / 难度 | `question_sets.question_count / est_minutes / difficulty` |
| 适配度 | `question_sets.match_score` |

### 5.4 作答（结构化）

| 字段 | 表 / 字段 |
| --- | --- |
| 题干 / 题型 / 作答建议 | `session_questions` + `questions` |
| 实时转写 | `session_questions.transcript`（流式追加） |
| 语音文件 | `session_questions.audio_url` |
| 剩余时间 | 客户端倒计时，提交时回传 `duration_ms` |

### 5.5 作答（群面）

| 字段 | 表 / 字段 |
| --- | --- |
| 讨论阶段 / 剩余时长 | `group_discussions.phase + total_minutes` |
| 小组成员 | `group_members`（含 `is_current_speaker`） |
| 发言流 | `group_timeline` 按 `started_at_ms` 排序 |
| 我的时长占比 | 计算字段 = `SUM(duration_ms WHERE member_id=我) / group_total_ms` |
| 打断他人次数 | `session_metrics.interrupt_count` |
| 被采纳观点 | `group_timeline.cited_count` |

### 5.6 综合评分报告

| 字段 | 表 / 字段 |
| --- | --- |
| 总分 | `reports.total_score` |
| 维度条 | `reports.dimensions` JSON |
| 较上场 / 同岗位百分位 | `reports.comparison` JSON |
| 逐题列表 | `session_questions` × `questions` |
| 高光时刻 | `report_highlights` |
| 加练 CTA | `report_recommendations.kind='practice'` |

### 5.7 逐题详情 / 回放

| 字段 | 表 / 字段 |
| --- | --- |
| 视频画面 | `session_questions.audio_url`（将来对接视频合成） |
| 倍速 | 客户端控制 |
| 转写全文 | `session_questions.transcript` |
| 高光时间戳 | `session_highlights.ts_ms` |
| 改进建议 / 参考答案 | `session_recommendations` |

## 6. UI 概要

### 6.1 风格基线
- 字体：**Sarasa Gothic SC**（中文）/ **Inter**（数字/英文）
- 主色：**#3E63DD**（蓝）；辅色：**#2FA36B**（成功绿）/ **#E8912D**（警示橙）
- 背景：**#F7F8FA**；卡片白：**#FFFFFF**
- 圆角：卡片 16px / 按钮 8-12px / 胶囊 999px
- 间距体系：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40

### 6.2 关键组件
| 组件 | 用在 | 说明 |
| --- | --- | --- |
| 顶部四步流程指示器 | 每个答题屏 | 已完成绿勾 / 当前蓝 / 待办灰；间距均分 |
| 数据卡片 | 工作台 / 报告 | 24 padding / 16 圆角 / 标签 + 大数字 |
| 维度评分条 | 报告 / 逐题详情 | 浅灰槽 + 实色填充，宽度按分值绝对像素 |
| 语音波形 | 作答中 | 5-7 条矩形柱体，高度随机，间隔 3-4 |
| 实时转写气泡 | 群面流 | 左侧他人灰 #F5F6F9 / 右侧自己蓝 #3E63DD |
| 字幕条 | 回放 | 深色 #1B2030 底 + 白字 |

### 6.3 移动端断点（375）
- 状态栏 62px + 内容容器 + 胶囊底部标签栏 62px
- 数据卡降为 2 列网格（wrap，间距 12）
- 主行动按钮（开始全真模拟 / 加练）满宽

## 7. 非功能性需求

| 类别 | 指标 |
| --- | --- |
| 性能 | 首屏 < 1.5s（桌面）/ 2s（移动）；语音流到首字 < 400ms |
| 可用性 | 模拟过程本地暂存，断网恢复后可继续；不丢字 |
| 隐私 | 录音仅本人在 24 小时内可回放；超期清理 |
| 容量 | 单场作答音频 ≤ 30MB（25 分钟 / 16kbps Opus）|
| 安全 | 手机号 + 短信验证码登录；JWT 8h 过期 |
| 兼容 | Chrome / Edge / Safari 最近两个大版本；移动端 iOS 14+ / Android 9+ |
| i18n | v1.0 仅简体中文，字段预留 `language` |
